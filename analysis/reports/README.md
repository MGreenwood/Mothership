# Analysis Reports

This directory contains generated analysis reports and documentation.

## Report Types

- `executive_summary.md` - High-level findings and conclusions
- `detailed_analysis.md` - Comprehensive technical analysis
- `evidence_report.md` - Compiled evidence with references
- `gap_analysis.md` - Claims vs reality comparison
- `recommendations.md` - Recommendations based on findings

## Report Generation

Reports are automatically generated from collected evidence and analysis results using the report generation tools.
