# Mothership Analysis Workspace

This directory contains all tools, scripts, and evidence for analyzing the Mothership application's actual functionality versus its advertised claims.

## Directory Structure

- `tools/` - Analysis scripts and utilities
- `evidence/` - Collected evidence and test results
- `logs/` - Analysis execution logs
- `reports/` - Generated analysis reports
- `config/` - Configuration files for analysis tools

## Usage

Run the analysis tools from this directory to systematically examine the Mothership codebase and functionality.
