# Analysis Tools

This directory contains scripts and utilities for analyzing the Mothership application.

## Tools Overview

- `code_analyzer.py` - Static code analysis tool
- `functional_tester.py` - Functional testing framework
- `evidence_collector.py` - Evidence collection and documentation
- `gap_analyzer.py` - Claims vs reality comparison tool
- `report_generator.py` - Analysis report generation

## Dependencies

- Python 3.8+
- Rust toolchain (for code compilation testing)
- PowerShell (for integration tests)
- Docker (for deployment testing)
